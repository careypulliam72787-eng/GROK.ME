# Seeker

Seeker is the flagship Solana Mobile device, purpose-built for crypto on Android.

Seeker is Solana Mobile’s flagship Android device, designed from the ground up for crypto. It’s the successor to the Saga and represents the next generation of crypto-native mobile hardware.

## Key features

* [**Seed Vault**](seed-vault.md) — A secure key custody system that keeps your private keys in a hardware-protected environment.
* [**dApp Store**](dapp-store.md) — An alternative crypto friendly app store for discovering Solana apps.
* [**Seeker Genesis Token**](../seeker-genesis-token.md) — An NFT minted once per device as proof of verified Seeker ownership.
* [**.skr Domain**](../.skr-domain.md) — A human-readable name that maps to your Solana wallet address.
