# FAQ

<details>

<summary>Do I need a Solana Mobile device to build an app for the dApp Store?</summary>

You do not need a Solana Mobile device to develop Android apps for the dApp Store. Developers **already** have all the tools necessary to start building apps for the dApp Store today! For more information, view our [developer documentation](development-setup.md).

</details>

<details>

<summary>How can I publish an app?</summary>

To publish an app, the summarized process is:

{% stepper %}
{% step %}
## Build a signed APK of your app

See the [Build and Sign an APK](../dapp-store/build-and-sign-an-apk.md) guide.
{% endstep %}

{% step %}
## Submit your app through the publisher portal

See the [Submit a New App](../submit-a-new-app.md) guide.
{% endstep %}
{% endstepper %}

</details>

<details>

<summary>Can I publish a web app onto the dApp Store?</summary>

Yes! With a few additional steps, you can wrap a web app in an Android app and generate an APK for app submission. For a tutorial and more information, view our [web app publishing guide](../recipes/general/publishing-a-web-app-on-the-dapp-store.md).

</details>

<details>

<summary>Can I get a developer kit for testing?</summary>

We are not running a developer device program for the Seeker, because you do not need a Solana Mobile device to develop Android apps for the dApp Store. Developers **already** have all the tools necessary to start building apps for the dApp Store today! For more information, view our [developer documentation](development-setup.md).

</details>

<details>

<summary>What does it mean for the dApp Store to be 'fee-free'?</summary>

Solana Mobile Inc. does not currently collect any fees on in-app purchases, app purchases, or subscriptions, nor are any fees collected on its behalf by apps in the catalog.

</details>

<details>

<summary>How can I see user statistics for my app in the dApp Store?</summary>

Developers are free to implement their own metric collection and logging within their apps. For example, [Google Analytics for Firebase](https://firebase.google.com/docs/analytics/get-started?platform=android) is a popular measurement solution that provides mobile SDKs.

</details>

<details>

<summary>I've published my app, now what?</summary>

Your submission is now in the app review process and publishers typically receive an update in 3-5 business days.

</details>
