# Solana Mobile developer documentation

## Developer documentation

Build Solana mobile applications with the Mobile Wallet Adapter, React Native tooling, and the Solana dApp Store.

### Quickstart

* [Development setup](https://docs.solanamobile.com/get-started/development-setup) — Set up your environment for Solana mobile development.
* [Create Solana Mobile App CLI](https://docs.solanamobile.com/get-started/react-native/create-solana-mobile-app) — Start a React Native Expo app with `create-solana-dapp`.

### Development guides

* [Add Mobile Wallet Adapter](https://docs.solanamobile.com/get-started/react-native/installation) — Integrate the Mobile Wallet Adapter SDK.
* [Detect Seeker users](https://docs.solanamobile.com/recipes/general/detecting-seeker-users) — Identify Seeker device users in your app.

### Solana dApp Store

* [dApp Store](https://docs.solanamobile.com/dapp-store/intro) — Learn how app listing works.
* [Publish an app](https://docs.solanamobile.com/dapp-store/submit-new-app) — Submit an app to the dApp Store.
* [Publish a web app](https://docs.solanamobile.com/recipes/general/publishing-a-web-app) — Wrap and publish a web app for Android.

### Resources

* [Sample apps](https://docs.solanamobile.com/sample-apps/sample_app_overview) — Review reference applications.
* [Recipes](https://docs.solanamobile.com/recipes/overview) — Follow task-focused implementation guides.
* [Development community](https://docs.solanamobile.com/get-started/community) — Connect with Solana Mobile developers.
